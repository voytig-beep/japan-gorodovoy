# Локальный прототип сайта «Японский городовой»

Дата: 10.11.2026.

Статус: подготовлен к публичной публикации через GitHub Pages.

## Состав

- `dist/index.html` — главная страница;
- `dist/t-technologies-tochka.html`, `dist/ozon-fire.html`, `dist/tatneft.html`, `dist/uralsib.html` — полные версии расследований на самом сайте;
- `dist/about.html`, `dist/advertising.html` — сведения о проекте, реклама и контакты;
- `dist/robots.txt`, `dist/sitemap.xml`, `dist/404.html` — поисковая индексация и обработка ошибочных ссылок;
- `dist/assets/site.css` — адаптивная редакционная стилистика;
- `dist/assets/site.js` — мобильное меню, поиск и фильтры архива, демонстрационная форма;
- `dist/assets/*.webp` — оптимизированные копии утверждённых обложек;
- `dist/assets/brand-logo.png` — копия эталонного логотипа проекта.

## Локальный просмотр

Из каталога `dist`:

```powershell
python -X utf8 -m http.server 8770 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8770/`.

Форма подписки ничего не передаёт и не сохраняет. Публикации на главной открываются внутри сайта; Пульс остаётся каналом коротких версий и переходов. Перед публичным запуском требуется принять решение о домене, аналитике, подписке и политике обработки данных.

## Публикация

GitHub Actions автоматически публикует содержимое `dist` на GitHub Pages после каждого изменения ветки `main`.
