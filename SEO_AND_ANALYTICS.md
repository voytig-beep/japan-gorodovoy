# SEO и аналитика сайта «Японский городовой»

## Что подключено

- Публичный адрес: `https://voytig-beep.github.io/japan-gorodovoy/`.
- Google Search Console: подтверждение файлом `dist/google857a974718ac6cd7.html`.
- Яндекс Метрика: счётчик `114170464`, загружается только после согласия посетителя.
- Вебвизор отключён. Включены карта кликов, точный отказ и отслеживание внешних ссылок.
- Карта сайта: `dist/sitemap.xml`.
- RSS: `dist/feed.xml`.
- Правила обхода: `dist/robots.txt`.

## Какие отчёты смотреть в Яндекс Метрике

1. **Посещаемость → Страницы входа** — какие материалы первыми открывают посетители.
2. **Содержание → Популярное** — просмотры каждой страницы сайта.
3. **Источники → Сводка** — переходы из Telegram, поисковых систем и других сайтов.
4. **Источники → Метки UTM** — сравнение конкретных публикаций и кампаний.
5. **Конверсии** — цели `telegram_click` и `pulse_click` после их создания в интерфейсе Метрики.

## Соглашение об UTM-метках

Для каждого внешнего анонса использовать отдельную ссылку. Названия кампаний писать латиницей, строчными буквами и через дефис.

### Telegram

`https://voytig-beep.github.io/japan-gorodovoy/ARTICLE.html?utm_source=telegram&utm_medium=social&utm_campaign=SLUG`

### Пример для Т-Технологий

- Telegram: `https://voytig-beep.github.io/japan-gorodovoy/t-technologies-tochka.html?utm_source=telegram&utm_medium=social&utm_campaign=t-tech-tochka`

В публикации Пульса внешнюю ссылку на сайт не добавлять: правила редакционного проекта запрещают сторонние URL без отдельного разрешения для конкретной статьи.

UTM-параметры не меняют канонический адрес: поисковики продолжают считать основной страницей URL без параметров.

## Что требует действий в кабинетах

- В Яндекс Вебмастере добавить сайт и подтвердить владение после получения проверочного кода.
- Передать `sitemap.xml` в Google Search Console и Яндекс Вебмастер.
- В Яндекс Метрике создать две JavaScript-цели: `telegram_click` и `pulse_click`.
- Через 7–14 дней проверить, какие страницы проиндексированы и по каким запросам появились показы.
