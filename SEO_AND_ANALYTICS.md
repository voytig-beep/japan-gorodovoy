## Соглашение об UTM-метках

Для каждого внешнего анонса использовать отдельную ссылку. Названия кампаний писать латиницей, строчными буквами и через дефис.

### Telegram

`https://voytig-beep.github.io/japan-gorodovoy/ARTICLE.html?utm_source=telegram&utm_medium=social&utm_campaign=SLUG`

### Пример для Т-Технологий

- Telegram: `https://voytig-beep.github.io/japan-gorodovoy/t-technologies-tochka.html?utm_source=telegram&utm_medium=social&utm_campaign=t-tech-tochka`

В публикации Пульса внешнюю ссылку на сайт не добавлять: правила редакционного проекта запрещают сторонние URL без отдельного разрешения для конкретной статьи.

UTM-параметры не меняют канонический адрес: поисковики продолжают считать основной страницей URL без параметров.
